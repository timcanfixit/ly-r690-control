        Web search
        
Provider: checking.... With a Serper key saved and enabled, searches use Google's results through Serper and fall back to DuckDuckGo if Serper fails; without one they use DuckDuckGo (keyless, but it can block this app - see below). Serper's free tier is 2,500 queries with no card; a full Profile Search uses up to 6.

        
        
        

        
Used by Profile Search below to find candidate pages online. Every query also runs a second time scoped to a curated list of known-good repair-forum and rework-equipment sites (badcaps.net, eevblog.com, reddit.com, ifixit.com, youtube.com, metcal.com, atlaspcb.com, pcbmay.com, chipquik.com, jbctools.com) and merges both - this can only find MORE candidates than a plain search, never fewer.

        
Real risk confirmed live 2026-09-09: DuckDuckGo's own bot-detection can block this app's requests without warning (an "anomaly" challenge instead of real results) - this app will never attempt to bypass that. Use Test search below to check whether it's currently working.

        
        

          
        

      

      

        Profile search (Ollama)
        
Searches the web for a real published reflow/rework profile for a board you name, then uses a local Ollama model to pull numbers out of whatever real page text is found - it never invents a profile from its own knowledge. Every result is tagged with its source page and never auto-loaded, auto-saved, or auto-sent.

    Service control
    
    
    Restarts this web service only - the Raspberry Pi is not rebooted and the machine itself is not touched. Use it after an update has been copied to the Pi. Refused while a run, cooldown, self-tune or unacknowledged fault is active, or while a run is being logged. This page reloads on its own once the service is back (about 10 seconds).
